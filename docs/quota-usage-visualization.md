# 요금·한도 사용량 표시

요금·한도 화면은 저장된 Gateway 요청을 기준으로 비용, 요청 수, 입·출력 합계 토큰을 일별 그래프와 월별 캘린더에 표시한다.

- 표시 지표에서 비용 / 요청 수 / 토큰을 선택한다. 비용 미기록 요청도 요청 수와 토큰에 포함된다.
- 상대 비교를 켜면 그래프 최고일을 100%로 표시한다. 꺼도 실제 데이터 최대값에 맞춰 금액 또는 수량 눈금을 자동 조정한다. 소액에 1달러 최소 눈금을 적용하지 않는다.
- USD와 KRW는 별도로 비교한다. 프로젝트·팀·키 비용 목록도 통화별 금액을 각각 표시한다.
- 그래프 점이나 날짜를 선택하면 실제 비용과 요청·토큰 수를 확인할 수 있다.
- 캘린더의 색과 비율은 표시 중인 월의 최고일을 기준으로 한다. 각 날짜에 실제 값과 요청 수가 나오며, 선택한 날짜의 비용·입력·출력 토큰을 하단에서 확인한다.
- 조회하지 않은 날짜는 0원으로 간주하지 않고 `미조회`로 표시한다. 표시 월에서 선택한 조회 범위에 해당하는 날짜만 월 합계에 포함한다.
- 조회 기간과 일별 집계는 서버의 UTC 날짜를 사용한다.
- 비용은 등록 단가 기반의 저장된 예상 비용이며, 외부 서비스의 최종 청구 금액을 가져오는 기능은 아니다.

`GET /api/admin/organizations/{organizationId}/quota-overview?all=true`는 해당 조직 프로젝트의 최초 요청일부터 종료일까지 반환한다. `all`이 생략되면 기존 최근 30일 기본값이 유지된다. 명시한 `from`은 `all`보다 우선한다.

검증: 프런트 `npm run test:quota`는 소액 눈금, 혼합 통화, 비용 없는 사용량, 월별 정규화·미조회 구분, 12자리 소수 보존을 확인한다. `SpendQuotaOverviewTest`는 전체 기간과 기본 기간, 빈 조직의 조회 범위를 확인한다.
